# 기사 프로젝트 노트

기사 프로젝트 하나를 한 페이지에 정리하는 노트입니다. HTML 파일 하나로 되어 있어서 서버나 설치 없이 브라우저에서 바로 열면 됩니다. 휴대폰 화면에서도 읽고 쓸 수 있게 만들었습니다.

## 구성

- **프로젝트 한 줄**: 프로젝트를 설명하는 브리프 한 줄을 적는 칸
- **주제**: 대주제 "경제"가 고정되어 있음
- **할 일 체크리스트**: 5개. 체크하면 줄이 그어짐
- **날짜별 기록**: 11/18부터 시작하는 타임라인. 세로선 위 점에 날짜가 찍히고 옆에 하루 한 줄을 적음. "+ 다음 날 추가"로 다음 날짜를 이어서 만듦

전화번호나 주소 같은 개인정보 칸은 없습니다.

## 사용법

1. `project-note.html`을 내려받습니다.
2. 브라우저(크롬, 사파리 등)에서 파일을 엽니다.
3. 칸을 눌러 바로 입력합니다.

입력한 내용은 브라우저의 `localStorage`에 자동 저장됩니다. 서버로 전송되지 않고, 같은 기기와 같은 브라우저에서만 유지됩니다. 다른 기기에서 열거나 브라우저 데이터를 지우면 비어 있습니다.

## 수정하기

파일 안에서 고칠 만한 부분은 두 곳입니다.

- **색상**: `<style>` 맨 위 `:root`의 CSS 변수(`--bg`, `--ink`, `--sub`, `--accent` 등)
- **시작 날짜**: `<script>` 안의 `START` 값(기본 `2026-11-18`)

색은 눈의 피로를 줄이도록 순백·순흑을 피하고, 글자와 배경의 대비를 WCAG 본문 기준(4.5:1) 이상으로 맞췄습니다.

| 용도 | 색 | 배경 대비 |
|---|---|---|
| 배경 | `#FAF9F7` | – |
| 본문 | `#2B2A28` | 13.6:1 |
| 보조 글자 | `#6B675F` | 5.4:1 |
| 강조 | `#7A5F38` | 5.7:1 |
